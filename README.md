# Handle Growth Agent

**AI-Powered Sales Automation for Insurance Brokers**

## Overview

Growth Agent is a proposal to systematize Handle's sales playbook for insurance brokers in LATAM. It demonstrates how to:

1. **Generate intelligent lead lists** - Score brokers by receptiveness and fit
2. **Personalize outreach at scale** - Not templates, actual context-aware messaging
3. **Capture insights automatically** - Extract pain points, objections, budget signals from conversations
4. **Evolve the playbook in real-time** - Based on conversation patterns, identify what works
5. **Predict and alert** - Forecast deal likelihood, surface stalling deals, recommend interventions

## The Problem

Handle has 75 active brokers and strong product-market fit. But Poncho is doing 80% of the sales.

Every broker conversation teaches something. Every objection reveal a pattern. But these learnings are scattered and don't scale.

## The Solution

An AI agent system that systematizes what Poncho learns manually, making it replicable and scalable.

